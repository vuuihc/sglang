## 0. 系列定位（一句话卖点）

> **别人讲原理，我讲"我真的租了卡、抓了 trace、复现了 bug，还诚实地说了哪些是假阳性"。**

国内讲 LLM 推理的文章 90% 是"翻译论文 + 讲架构"，稀缺的是**可复现的一手实战 + 诚实的负结论**。这就是本系列的差异化护城河。四篇主线合起来，讲的是一件事：**一个工程师如何从零成为能给成熟推理引擎提 PR 的人**。

## 4. 每篇成稿的统一检查清单（发布前逐项过）

- [ ] **钩子前 200 字**：先抛一个反直觉结论或悬念（例：「我抓完 trace 发现，小 batch 居然不是 host-bound」），别先讲背景。
- [ ] **至少 1 张 trace 截图**：Perfetto 泳道图 / 三张表截图。文字讲不清的地方一定上图。
- [ ] **至少 1 个"诚实时刻"**：写清哪个是假阳性、哪个结论被推翻。这是本系列的信任来源。
- [ ] **每个关键结论配一个具体数字**（见上表"核心硬料"），不空泛。
- [ ] **可复现**：贴出关键脚本命令（`scripts/` 里的），让读者能照做。
- [ ] **收口给"下一步"**：结尾指向系列下一篇，形成追更。
- [ ] **敏感信息**：清掉 `history/.env_*`、remote 主机 IP、内部路径。发布前 grep 一遍。
- [ ] **平台适配**：公众号版合并小标题、少代码多图；知乎版可保留完整代码块与表格。
